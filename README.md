# Formatador de Leads para WhatsApp  

## 📌 Visão Geral  
Ferramenta de processamento de dados para padronização de números de telefone em bases do Excel, desenvolvida para otimizar campanhas de comunicação via WhatsApp. Remove caracteres não numéricos, valida formatos e prepara arquivos para uso em ferramentas de disparo.

---

## 🚀 Instalação  
**Instale as dependências:**:  
```bash  
pip install -r requirements.txt
```

## Rodar o programa
Para executar o programa, utilize o comando:
```bash  
python main.py
```

## Configurações

Ajsute o código com os caminhos, nome das planilhas e cabeça~lho de acordo com as especificidades do seu Excel.
